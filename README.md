# Práctica de Git y GitHub

Repositorio de aprendizaje de control de versiones con una página HTML y notas de comandos.

## Alcance

Proyecto de formación. El contenido disponible puede consultarse en [index.html](index.html) y [pasos Git.txt](pasos%20Git.txt). No se presenta como un producto listo para uso comercial.

## Ejecución local

```bash
git clone https://github.com/Franc-Devel/PracticaGityGithub.git
cd PracticaGityGithub
python3 -m http.server 8000
```

Abrir `http://localhost:8000/index.html`. El servidor estático sólo sirve archivos; no implementa una API ni envía formularios a un servicio.
